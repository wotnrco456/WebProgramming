1. 프로젝트 개요

1.1 주제

GameDev PatternHub - 게임 개발을 위한 디자인 패턴 학습 플랫폼

1.2 배경

게임 개발에서 디자인 패턴은 복잡한 게임 로직을 체계적으로 관리하고 코드의 재사용성과 유지보수성을 높이는 중요한 도구입니다. 하지만 많은 게임 개발 초보자들이 디자인 패턴의 개념을 이해하기 어려워하고, 실제 게임 개발에 어떻게 적용해야 하는지 막막해합니다.

이러한 문제를 해결하기 위해 이론적 설명과 실제 코드 예시, 그리고 Unity 미니게임 데모를 통해 디자인 패턴을 쉽고 재미있게 학습할 수 있는 웹 플랫폼을 개발하게 되었습니다.

1.3 목표

  • 게임 개발에 필요한 주요 디자인 패턴 11개를 체계적으로 학습할 수 있는 플랫폼 제공
  • 이론 설명, 코드 예시(C#, C++), Unity 실습 게임을 통한 통합적 학습 경험 제공
  • 반응형 웹 디자인을 통한 다양한 디바이스에서의 접근성 보장
  • 다크/라이트 테마, PDF 문서 뷰어 등 사용자 편의 기능 제공
  • 직관적이고 현대적인 UI/UX를 통한 학습 동기 부여

(function() {
    const savedTheme = localStorage.getItem('theme') || 'light';
    document.documentElement.setAttribute('data-theme', savedTheme);
})();

// 테마 전환 기능
themeToggle.addEventListener('click', function() {
    const currentTheme = htmlElement.getAttribute('data-theme');
    const newTheme = currentTheme === 'light' ? 'dark' : 'light';
    
    htmlElement.setAttribute('data-theme', newTheme);
    localStorage.setItem('theme', newTheme);
    updateThemeIcon(newTheme);
});

filterButtons.forEach(button => {
    button.addEventListener('click', function() {
        const category = this.getAttribute('data-category');
        
        patternCards.forEach(card => {
            if (category === 'all' || card.getAttribute('data-category') === category) {
                card.style.display = 'flex';

                card.style.display = 'none';

  3. 반응형 확인: 브라우저 창 크기 조절로 반응형 레이아웃 확인
  4. 패턴 카드: 11개 디자인 패턴 카드의 호버 효과 및 클릭

4.1.2 패턴 학습 시스템

  1. 패턴 목록: patterns.html에서 카테고리별 필터링 기능 시연

  4. HTML 특수문자: C++/C# 코드의 <, >, & 문자 올바른 표시 확인

4.1.3 Unity 게임 데모

  1. 게임 로딩: demo-game.html에서 Unity WebGL 게임 자동 로딩
  2. 게임 플레이: 키보드 조작으로 게임 플레이
  3. 컨트롤 패널: 전체화면, 재시작, 음소거 기능 테스트
  4. 패턴 설명: "적용 패턴" 탭에서 게임에 사용된 11개 패턴 설명 확인

4.1.4 PDF 문서 뷰어

  2. 페이지 네비게이션: 이전/다음 페이지 버튼 및 페이지 점프
  3. 줌 기능: 확대/축소 버튼 및 드롭다운 선택

3. 추가 학습한 내용과 적용 기술

3.1 수업 외 추가 학습 기술

PDF.js 라이브러리

학습 내용: Mozilla에서 개발한 JavaScript 기반 PDF 렌더링 라이브러리

적용 위치: document.html 페이지의 PDF 뷰어

핵심 기능: PDF 페이지 렌더링, 줌 기능, 페이지 네비게이션, 전체화면 모드

highlight.js 라이브러리

학습 내용: 웹에서 코드 구문 강조를 위한 JavaScript 라이브러리

적용 위치: patterns/codes/ 디렉토리의 모든 코드 예시 페이지

핵심 기능: C#, C++ 코드 구문 하이라이팅, 다크 테마 지원

Unity WebGL 통합

학습 내용: Unity 엔진에서 WebGL로 빌드된 게임을 웹페이지에 통합하는 방법

적용 위치: demo-game.html 페이지

핵심 기능: Unity 인스턴스 제어, 게임과 웹페이지 간 통신, 로딩 프로그레스

Fetch API & JSON 데이터 처리

학습 내용: 비동기 데이터 로딩과 JSON 파싱

적용 위치: patterns-detail.html의 동적 콘텐츠 로딩

핵심 기능: 패턴별 상세 정보를 JSON 파일에서 로드하여 동적으로 페이지 생성

CSS 커스텀 속성(CSS Variables)

학습 내용: CSS 변수를 활용한 테마 시스템 구현

적용 위치: 전체 프로젝트의 다크/라이트 테마

핵심 기능: 동적 테마 전환, 색상 일관성 유지

반응형 웹 디자인

학습 내용: CSS Grid, Flexbox, 미디어 쿼리를 활용한 반응형 레이아웃

적용 위치: 모든 페이지의 레이아웃

핵심 기능: 다양한 화면 크기에 대응하는 적응형 UI

3.2 수업에서 배운 기술의 심화 적용

3.2.1 Document Object Model (DOM) 심화 활용

  • 동적 HTML 콘텐츠 생성 및 조작
  • 이벤트 위임을 통한 효율적인 이벤트 처리
  • DocumentFragment를 활용한 성능 최적화

3.2.2 Browser Object Model (BOM) 활용

  • localStorage를 통한 사용자 설정 저장
  • History API를 활용한 SPA 구현
  • 전체화면 API 활용

3.2.3 JavaScript 이벤트 처리 고도화

  • 키보드 단축키 시스템 구현
  • 모바일 터치 이벤트 처리
  • 커스텀 이벤트 생성 및 활용

3.2.4 CSS3 고급 기능

  • CSS 애니메이션과 트랜지션을 활용한 인터랙티브 UI
  • CSS Grid와 Flexbox의 조합을 통한 복잡한 레이아웃
  • CSS 필터와 블렌드 모드를 활용한 시각적 효과

5. 소감

5.1 프로젝트를 통해 얻은 성과

기술적 성장

이번 프로젝트를 통해 단순한 정적 웹페이지를 넘어서 동적이고 인터랙티브한 웹 애플리케이션을 구현할 수 있었습니다. 특히 HTML5의 최신 기능들과 CSS3의 고급 기능, JavaScript의 모던 문법을 실제 프로젝트에 적용해보면서 웹 기술에 대한 이해가 크게 향상되었습니다.

가장 인상깊었던 것은 Unity WebGL과 웹페이지의 통합이었습니다. 게임 엔진에서 빌드된 콘텐츠를 웹브라우저에서 실행하고, JavaScript를 통해 게임과 웹페이지 간의 상호작용을 구현하는 과정에서 웹 기술의 무한한 가능성을 느낄 수 있었습니다.

문제 해결 능력 향상

개발 과정에서 다양한 기술적 문제들을 마주했습니다. PDF.js 라이브러리 통합 시 발생한 CORS 문제, Unity WebGL 로딩 최적화, 반응형 레이아웃에서의 브라우저 호환성 문제 등을 해결하면서 문제 분석과 해결 능력이 크게 향상되었습니다.

특히 HTML에서 C#, C++ 코드를 표시할 때 <, >, & 등의 특수문자를 &lt;, &gt;, &amp;로 이스케이프 처리하는 과정에서 웹 표준과 보안의 중요성을 깊이 이해하게 되었습니다.

사용자 경험 설계

기술적 구현뿐만 아니라 사용자의 관점에서 웹사이트를 설계하는 방법을 학습했습니다. 다크/라이트 테마 제공, 직관적인 네비게이션, 로딩 상태 표시, 반응형 디자인 등을 통해 사용자 중심의 웹 개발 철학을 실천할 수 있었습니다.

5.2 아쉬웠던 점과 개선 방향

성능 최적화

Unity WebGL 게임의 로딩 시간이 다소 긴 편이어서 사용자 경험에 아쉬움이 있었습니다. 향후 게임 에셋 최적화, 프리로딩 시스템 구현, 또는 Progressive Web App 기술을 활용하여 성능을 개선하고 싶습니다.

접근성 개선

시각적 디자인에 집중하다 보니 웹 접근성 가이드라인을 완전히 준수하지 못한 부분이 있었습니다. 향후 스크린 리더 지원, 키보드 네비게이션 개선, 색상 대비 최적화 등을 통해 모든 사용자가 접근할 수 있는 웹사이트로 발전시키고 싶습니다.

컨텐츠 확장

현재는 11개의 디자인 패턴만 다루고 있지만, 향후 SOLID 원칙, 아키텍처 패턴, 게임 특화 패턴 등으로 컨텐츠를 확장하여 더욱 포괄적인 학습 플랫폼으로 발전시키고 싶습니다.

5.3 향후 발전 계획

단기 계획 (1-3개월)

  • 웹 접근성 가이드라인 완전 준수
  • Progressive Web App(PWA) 구현
  • 다국어 지원 시스템 추가
  • 사용자 피드백 시스템 구현

중기 계획 (3-6개월)

  • 백엔드 시스템 구축 (Node.js, MongoDB)
  • 사용자 계정 및 학습 진도 관리
  • 인터랙티브 코딩 실습 환경 구축
  • AI 기반 개인화 학습 추천 시스템

장기 계획 (6개월 이상)

  • 모바일 앱 버전 개발
  • VR/AR을 활용한 3D 학습 환경
  • 실시간 협업 학습 기능
  • 게임 개발 커뮤니티 플랫폼 구축

5.4 최종 소감

이번 웹프로젝트는 단순히 수업에서 배운 내용을 복습하는 것을 넘어서, 실제 사용자에게 가치를 제공하는 웹 애플리케이션을 만들어보는 소중한 경험이었습니다. HTML5, CSS3, JavaScript의 기초부터 PDF.js, Unity WebGL 통합 같은 고급 기술까지 폭넓게 학습하면서 웹 개발자로서의 역량을 크게 향상시킬 수 있었습니다.

특히 게임 개발이라는 저의 관심 분야와 웹 기술을 접목시켜 의미 있는 프로젝트를 완성할 수 있어서 매우 뿌듯합니다. 앞으로도 지속적으로 이 프로젝트를 발전시켜 나가며, 게임 개발을 배우는 많은 사람들에게 도움이 되는 플랫폼으로 만들어가고 싶습니다.

마지막으로, 이런 의미 있는 프로젝트를 진행할 수 있도록 지도해주신 교수님께 깊은 감사를 드립니다. 이번 경험을 바탕으로 앞으로도 더욱 발전하는 개발자가 되겠습니다.
